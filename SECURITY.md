# Security policy

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Use the
repository's **Security → Report a vulnerability** private advisory flow when
available. If that flow is unavailable, contact the repository owner privately
through their GitHub profile and include only enough detail to establish a safe
contact channel.

Include the affected version, Home Assistant version, impact, reproduction
conditions, and a proposed mitigation if known. Remove credentials, private
node identifiers, locations, and unredacted diagnostics.

The current supported production line for security review is MeshCore NOC v4
on `main`. Development builds remain available from `v4-development`. Please
allow maintainers time to validate and coordinate a fix before public
disclosure.
