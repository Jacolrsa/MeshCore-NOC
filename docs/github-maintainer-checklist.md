# GitHub repository presentation checklist

- Description: `Home Assistant Network Operations Centre for MeshCore repeaters and clients.`
- Suggested topics: `home-assistant`, `meshcore`, `lora`, `network-monitoring`,
  `noc`, `custom-integration`, `battery-monitoring`, `iot`.
- Website: link to the most useful published documentation page, or leave
  blank until one exists.
- Social preview: upload `docs/images/github-social-preview.png` under
  **Settings → General → Social preview**.
- Confirm the default branch and branch protections reflect the release
  workflow.
- Confirm private vulnerability reporting is enabled before directing users to
  GitHub Security Advisories.
